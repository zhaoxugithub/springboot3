# 静态资源访问问题解决方案

## 问题描述
访问 `http://localhost:9000/static/1.txt` 时出现 404 错误：
```
Resolved [org.springframework.web.servlet.resource.NoResourceFoundException: No static resource 1.txt.]
```

## 问题原因
虽然在 `application.properties` 中配置了静态资源位置：
```properties
spring.web.resources.static-locations=classpath:/a/,classpath:/b/,classpath:/static/,classpath:/c/
spring.mvc.static-path-pattern=/static/**
```

但是在 `MyConfig.java` 中通过代码方式配置了静态资源处理器，**代码配置会覆盖 properties 配置文件的配置**：
```java
@Override
public void addResourceHandlers(ResourceHandlerRegistry registry) {
    registry.addResourceHandler("/static/**")
            .addResourceLocations(
                    "classpath:/a/",
                    "classpath:/b/"  // ❌ 只配置了 /a/ 和 /b/，缺少 /c/ 和 /static/
            ).setCacheControl(CacheControl.maxAge(1180, TimeUnit.SECONDS));
}
```

由于 `1.txt` 文件位于 `/resources/c/1.txt`，而代码中没有配置 `/c/` 目录，因此无法访问。

## 解决方案

### ✅ 已修复
在 `MyConfig.java` 的 `addResourceHandlers` 方法中添加了缺失的目录：
```java
@Override
public void addResourceHandlers(ResourceHandlerRegistry registry) {
    registry.addResourceHandler("/static/**")
            .addResourceLocations(
                    "classpath:/a/",
                    "classpath:/b/",
                    "classpath:/c/",      // ✅ 添加 /c/ 目录
                    "classpath:/static/"  // ✅ 添加 /static/ 目录
            ).setCacheControl(CacheControl.maxAge(1180, TimeUnit.SECONDS));
}
```

## 测试访问
修复后，重启应用，以下 URL 应该都能正常访问：
- `http://localhost:9000/static/1.txt` → 访问 `/c/1.txt`
- `http://localhost:9000/static/2.jpg` → 访问 `/b/2.jpg`
- `http://localhost:9000/static/3.jpg` → 访问 `/a/3.jpg`
- `http://localhost:9000/static/4.jpg` → 访问 `/static/4.jpg`
- `http://localhost:9000/static/index.html` → 访问 `/static/index.html`

## 重要提示

### 配置优先级
Spring Boot 中，Java 代码配置 > application.properties 配置。

如果通过 `WebMvcConfigurer` 的 `addResourceHandlers` 方法配置了静态资源，那么：
- ✅ 会保留其他默认配置（如果不调用 `registry.addResourceHandler()` 的话）
- ❌ 如果调用了 `registry.addResourceHandler("/static/**")`，则会覆盖该路径模式的所有配置

### 最佳实践
1. **统一配置位置**：要么全部用 properties 配置，要么全部用代码配置，避免混用
2. **如果需要混用**：
   - 代码配置中要包含 properties 中的所有路径
   - 或者不在代码中配置静态资源，让 properties 配置生效

3. **当前项目建议**：
   - 如果主要使用 properties 配置，可以注释掉 `MyConfig.java` 中的 `webMvcConfigurer` Bean
   - 如果使用代码配置，确保所有需要的路径都在代码中配置（已修复）

## 相关文件位置
- 配置文件：`src/main/resources/application.properties`
- Java 配置：`src/main/java/com/atguigu/web/config/MyConfig.java`
- 静态资源目录：
  - `src/main/resources/a/` → 包含 `3.jpg`
  - `src/main/resources/b/` → 包含 `2.jpg`
  - `src/main/resources/c/` → 包含 `1.txt`
  - `src/main/resources/static/` → 包含 `4.jpg`, `index.html`, `favicon.ico`
